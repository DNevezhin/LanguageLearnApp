# LanguageLearnApp

REST API для образовательной платформы по изучению языков программирования с интегрированным ИИ-ментором.

Проект реализует систему авторизации пользователей, работу с реляционной базой данных PostgreSQL, автоматическое наполнение контента (Data Seeding) на основе конфигурационных файлов и интеграцию с локальной языковой моделью (LLM) для проверки исходного кода и ведения контекстного диалога с обучающимся.

## Стек технологий
- **Платформа:** C# (.NET 9) / ASP.NET Core Web API
- **База данных:** PostgreSQL
- **ORM:** Entity Framework Core (Code First, Миграции)
- **Аутентификация:** JWT (JSON Web Tokens), BCrypt.Net (хеширование паролей)
- **ИИ-интеграция:** Ollama (модель Qwen 2.5), OllamaSharp, Microsoft.Extensions.AI
- **Тестирование:** xUnit, EF Core In-Memory Database

## Функциональные возможности
- **Аутентификация и авторизация:** Регистрация пользователей, аутентификация, безопасное хранение учетных данных, защита эндпоинтов с помощью JWT (Bearer-схема).
- **Управление учебным процессом:** Получение списка доступных уроков с фильтрацией по языкам программирования, вывод теоретического материала и связанных практических задач.
- **Интеллектуальный менторинг:** Интерактивная проверка кода пользователя в реальном времени. Система функционирует по принципу наводящих вопросов, направляя студента к верному решению без предоставления готового кода. Поддерживается сохранение истории диалога в базе данных для сохранения контекста.
- **Автоматическое наполнение (Data Seeding):** При первом запуске приложение автоматически разворачивает структуру базы данных и импортирует учебные курсы по C#, Python и C++ из структурированных JSON-файлов.
- **Тестирование:** Ключевые сценарии аутентификации (успешная регистрация и обработка дубликата логина) покрыты юнит-тестами. Для изоляции тестов применяется xUnit и база данных In-Memory.
- **Интерфейс:** Демонстрационный веб-интерфейс (HTML/CSS/JS). Так как проект сфокусирован на бэкенд-архитектуре, фронтенд реализован с применением генеративных инструментов автоматизации.

## Структура проекта
```text
├── Controllers/              # API эндпоинты (Auth, Lessons, Chat, Progress)
├── Services/                 # Бизнес-логика (IAiService, ILessonService), изолированная от контроллеров
├── Entities/                 # Сущности базы данных для EF Core
├── Models/                   # DTO для запросов/ответов и модели для парсинга данных
├── Data/                     # Контекст базы данных (AppDbContext)
├── SeedData/                 # JSON-файлы с теорией и задачами для автогенерации курсов
├── LearninLanguageApp.Tests/ # Проект с юнит-тестами (xUnit)
└── wwwroot/                  # Фронтенд-интерфейс приложения
```

## Системные требования
- .NET 9 SDK
- СУБД PostgreSQL
- Локальный сервер Ollama с загруженной моделью `qwen2.5-coder:7b` или `qwen2.5:7b`

## Инструкция по развертыванию и запуску
1. Склонируйте репозиторий с исходным кодом.
2. В файле конфигурации `appsettings.json` укажите корректную строку подключения к PostgreSQL (`DefaultConnection`) и секретный ключ для подписи токенов (`JwtSettings:SecretKey`).
3. Выполните команду для применения миграций и автоматического создания структуры таблиц:
   ```bash
   dotnet ef database update
   ```
4. Запустите приложение:
   ```bash
   dotnet run
   ```
5. Перейдите по адресу запущенного приложения для тестирования эндпоинтов через Swagger UI или взаимодействия с веб-интерфейсом.

## Запуск тестов
Для запуска юнит-тестов выполните команду в корне решения:
```bash
dotnet test
```
